# Minesweeper

Учебный проект по C++ - игра "Сапёр" в консоли.


## Как играть

- `#` - закрытая клетка
- `F` - флаг
- цифры `1`-`8` - количество мин вокруг открытой клетки
- пустая клетка - открытая клетка без мин рядом
- `X` - мина (при поражении)

Управление:
- Вводишь номер строки и столбца через пробел (`3 5`)
- Далее букву действия: `o` — открыть, `f` - поставить/снять флаг
